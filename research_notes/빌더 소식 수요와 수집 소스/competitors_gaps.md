## 한국어 서비스는 무엇을, 얼마나 자주, 어떻게 다루고 얼마나 인기 있는가

## 해외 서비스는 어떻게 하고 있는가

### Takeaway
규모는 사람 편집형(TLDR, Techmeme, Ben's Bites)과 AI 파이프라인을 공개적으로 쓰는 AINews가 함께 만든다. 판단형 리뷰의 기준점은 Console.dev이고, 레포 지표(Trendshift, OSS Insight)와 수명 추적(BenchLM 등)은 각각 좁은 도구로 나뉘어 있다.

### Cited Findings
- TLDR: 8,000,000명 이상 독자를 내세우는 무료 일간 메일, 스타트업·기술·프로그래밍 요약 — [TLDR](https://tldr.tech/) (직접 확인, 측정 시점 미표시)
- Techmeme: 크롤링·소프트웨어가 뒷받침하고 사람 편집자가 최종 선정과 제목을 맡는 구조 — [Techmeme About](https://techmeme.com/about)
- Hacker Newsletter: 금요일 주간, 60,000명 이상, 사람 손 선별. 푸터는 2025라 현재 활동은 "다음 호 금요일" 문구로만 추정 — [Hacker Newsletter](https://hackernewsletter.com/)
- Console.dev: 최신 호 2026-10-29, 매주 목요일, 3만 명 이상, 도구 2~3개 리뷰, 항목마다 좋은 점과 아쉬운 점을 적고, 베타 목록과 RSS·MCP 제공 — [Console](https://console.dev/)
- AINews: 최신 호 10월 31일, 평일 발행, 749개 글, 이제 latent.space/news로 이동 — [Latent Space News](https://latent.space/news/). 2026-01-23 Latent Space 합류, 약 80,000 구독자, Discord·Reddit·X 토론을 요약 — [Latent Space wiki](https://latent.space/wiki/ainews-3db8768a/) (자사 위키). "99% 연구 에이전트 생성"은 제3자 소개문 — [AI Council](https://aicouncil.com/profile/swyx-shawn-wang). 호 하나가 18~37분 분량 — [Latent Space News](https://latent.space/news/)
- Ben's Bites: 140k+ 구독, 오픈율 37%(광고 페이지 자기 신고, 날짜 없음) — [Ben's Bites 광고](https://ads-main.bensbites.com/)
- daily.dev: 일간 활성 10만이라는 광고 대행사 수치, 확장 프로그램 설치 40만 이상 등 수치가 서로 다르고 시점 불명 — [BuySellAds](https://discover.buysellads.com/daily-dev), [Extension Auditor](https://extensionauditor.com/scan/daily-dev-the-homepage-developers-deserve-jlmpjdjjbgclbocgajdjefcidcncaied)
- Trendshift: GitHub Trending 대안, 뜨는 순간을 잡는다고 내세움. 일·주·월·연 보기, 실시간 언급. 점수 공식은 미공개 — [Trendshift](https://trendshift.io/)
- OSS Insight: GitHub 이벤트 기반 분석, 2026년 자료가 있어 운영 중으로 보이나 직접 확인은 안 함 — [daily.dev 목록](https://daily.dev/blog/best-developer-tool-directories/)
- 모델 수명 추적: BenchLM Radar는 303개 모델 은퇴 일정, 90·30·7일 전 알림, 달력 피드, RSS·JSON, MCP 제공(영어, 가격 추적 기능은 아님) — [BenchLM](https://benchlm.ai/newsletter/issues/2026-08-27). Vorp Labs는 업체마다 날짜 신뢰도가 다르다고 적음(구글은 가장 이른 날짜, Anthropic은 확정 전 잠정) — [Vorp Labs](https://vorplabs.com/models/deprecations). modelfax는 공급사 페이지를 매일 읽어 git 이력으로 가격 변화를 남김 — [modelfax](https://github.com/bytebrujo/modelfax). llm-eol도 Azure·Vertex·Bedrock까지 수집 — [llm-eol](https://github.com/binhna/llm-eol). Model Graveyard는 카운트다운과 대체 모델 제안 — [Product Hunt](https://www.producthunt.com/posts/1192198)

### Inferences
- 해외에서 살아남은 축은 (1) 사람이 고르고 제목을 쓰는 곳, (2) 좋고 나쁨을 적는 리뷰, (3) 원 토론을 압축하는 긴 요약이다. 단순 링크 요약만으로 키운 사례는 이번 조사에서 확인되지 않았다.
- 모델 은퇴 데이터는 영어권에서 이미 공짜 상품이다. 데이터 자체를 다시 만들 이유는 없고, modelfax나 공식 페이지를 입력으로 쓰고 "한국 웹 개발자에게 어떤 뜻인가"를 얹는 쪽이 맞다.

### Gaps
- There's An AI For That은 403으로 못 열었고, Futurepedia, Toolify의 현황·트래픽은 찾지 못했다. 이들의 트래픽 감소 여부는 근거 없음.
- Changelog는 제3자 사이트에 뉴스레터 비활성 표시가 있으나 날짜가 없어 믿기 어렵다 — [InboxReads](https://inboxreads.co/n/changelog-weekly). DevHunt, BetaList는 2026년 활동 미확인.

## AI 생성 다이제스트는 어떻게 받아들여지고, 왜 되거나 안 되는가

### Takeaway
불만의 핵심은 AI라는 사실보다 내용이 없다는 점이다. 길고, 뻔하고, 제목을 되풀이하고, 원 토론의 맛을 잃는다. 사람들이 좋아한 것은 "읽을지 말지 빨리 고르기"였다.

### Cited Findings
- HN의 HackYourNews 토론에서 좋았던 점은 빠른 선별, 댓글 요약, 과장 뺀 제목. 싫었던 점은 장황함, 상투적 도입부, 글과 댓글 요약의 중복, 오류, HN 전문가 토론보다 못함, 시간이 오히려 절약되지 않는다는 의심 — [HN, 2023](https://news.ycombinator.com/item?id=37427127)
- HN 요약 저장소는 넘쳐남(일간 LLM 요약 등) — [hn-digest](https://github.com/sharpnk/hn-digest), [hn-brief](https://github.com/NickJLange/hn-brief). 2026년 10월 자동 다이제스트 예시 중에는 표의 한 줄 요약이 제목을 사실상 되풀이하는 것도 있음 — [ai-radar](https://github.com/HuggerHustle/ai-radar/issues/58)
- Gergely Orosz는 시니어 엔지니어가 추천을 부탁한 Substack 글이 사람 손을 안 거친 AI 산출물이라며 공개적으로 slop이라 했음 — [Digg 요약](https://digg.com/tech/nxjiikbq) (2차 출처)
- ARLnow는 ChatGPT API로 만든 아침 메일을 중단했음 — [ARLnow](https://www.arlnow.com/2024/06/03/arlnow-to-discontinue-ai-generated-email-newsletter/). 다만 편집자는 이 메일에 대한 명시적 부정 반응보다 다른 AI 기능에 대한 반응이 있었다고 함 — [Nieman Lab](https://niemanlab.org/?p=214857)
- AI 작성 뉴스레터 포럼 토론에서 "AI 생성 요약" 표시만 있었어도 달랐을 것이라는 의견이 있음 — [UHK 포럼](https://forum.uhk.io/t/ai-written-augmented-newsletter/2910)
- GeekNews 이용자도 AI 요약과 사람 글의 품질 차이를 느끼면서 동시에 GN+를 찾아 읽음 — [GeekNews 토론](https://news.hada.io/topic?id=11208)
- GeekNews에 마틴 파울러의 LLM 문체 글이 31점으로 상위에 있어, 개발자 독자가 LLM 문체에 민감하다는 신호로 볼 수 있음 — [GeekNews](https://news.hada.io/)

### Inferences
- 성공 조건: AI 사용을 표시, 사람이 또는 명시 기준이 선별, 짧게, 출처 링크, 요약이 아니라 추가 정보(비교, 영향, 이력)를 줄 것.
- 실패 조건: 제목 다시 쓰기, 항목 수 채우기, 근거 없는 "혁신적" 표현, 오류 정정 경로 없음. Tidwyn은 이미 '정정됨' 표시가 있어 신뢰 측면에서 쓸 수 있다.
- "할 일 없음"을 말하는 판단(대부분은 무시해도 됨)이 슬롭의 반대편이다. 이는 근거 자료에서 끌어낸 추정이고 독자 실험은 없다.

### Gaps
- 요약 정확도를 체계적으로 잰 자료나, AI 다이제스트의 유지율·이탈 수치는 찾지 못했다. 위 근거는 대부분 일화다.
- HN 표본의 핵심이 2023년 글이라 최신 정서와 다를 수 있다. 한국어권의 AI 요약 불만 자료도 얕다.

## 한국어로 아무도 안 하는 것은 무엇인가

### Takeaway
도구별 변화를 시간순으로 쫓고, 내 스택에 미치는 영향과 기한을 말해 주는 한국어 일간 서비스는 이번 조사에서 찾지 못했다. 정적인 비교 글과 레포 단위 평가는 이미 있으므로, 빈자리는 "시간 축 + 영향 판단"이다.

### Cited Findings
- 한국어 Claude Code·Cursor 비교 글은 많지만 대부분 날짜 불명의 정적 가이드이거나 업체 블로그이고, 검색으로는 가격 인상이나 지원 종료를 다룬 소식형 글이 나오지 않았음 — [wavespeed](https://wavespeed.ai/blog/ko/posts/cursor-vs-claude-code-comparison-2026/), [Novita](https://blogs.novita.ai/ko/claude-code-vs-cursor/), [braindetox](https://braindetox.kr/posts/ai_coding_tools_2026_comparison.html)
- 깃밥은 레포 간 맛대결·신뢰도를 제공해 "비교"가 전혀 없는 것은 아님 — [깃밥](https://gitbap.com/)
- Console.dev의 좋은 점·아쉬운 점 형식은 영어로 존재 — [Console](https://console.dev/)
- 모델 은퇴 달력은 영어로 존재(BenchLM, Vorp Labs). 찾은 추적기 중 한국어판은 없었음 — [BenchLM](https://benchlm.ai/newsletter/issues/2026-08-27), [Vorp Labs](https://vorplabs.com/models/deprecations)

빈자리 판단표(서비스 확인 범위 안에서):

| 기능 | 한국어 현황 | 영어 현황 |
| --- | --- | --- |
| 무슨 일이 있었나(요약) | 포화: GN⁺, 뉴스레터 | 포화 |
| 트렌딩 레포 한국어 설명 | 있음: 깃밥 | 있음 |
| 레포 단위 신뢰 라벨 | 있음: 깃밥 | Trendshift 등 지표 |
| "내가 신경 써야 하나" 판단 | 찾지 못함 | Console.dev가 부분적 |
| 기존 도구와 비교 | 정적 가이드만, 소식에 붙은 형태는 못 찾음 | 부분적 |
| 마이그레이션 영향·기한 | 찾지 못함 | 은퇴 달력 있음, 대체 모델 제안 일부 |
| 한 도구를 시간순 추적 | 찾지 못함 | 데이터 추적기는 있고 해설은 드묾 |
| 제품 소식을 업계 이슈 흐름과 연결 | 찾지 못함 | 미확인(AINews 호 내부 구조를 보지 못함) |

### Inferences
- 가장 방어 가능한 조합은 시간 축이다. 한 번 쓰는 요약은 누구나 복제하지만 몇 달 쌓인 도구별 기록은 복제가 느리다.
- 비교·판단은 근거가 필요하다. AI가 근거 없이 "써 보세요"라고 하면 슬롭이 되므로, 판단은 공식 문서의 사실(가격, 호환 깨짐, 기한)에 묶는 편이 안전하다.

### Gaps
- "아무도 안 한다"는 것은 부재 증거다. 검색 도구가 한국어 뉴스레터와 메일리 글을 잘 잡지 못해 작은 개인 뉴스레터는 놓쳤을 수 있다.

## Tidwyn의 기존 자산으로 무엇을 다르게 만들 수 있는가

### Takeaway
경쟁자에게 없는 것은 데이터 구조다. 소식 하나를 이슈 스레드, 엔티티, 달력, 지표에 연결하면 "요약"이 아니라 "기록"이 된다. 아래는 조사에서 끌어낸 제안이며, 이번 조사에서 Tidwyn 코드는 읽지 않았다.

### Cited Findings
- 은퇴 날짜는 알림 가치가 입증된 형태다: 90·30·7일 알림, 달력 피드 — [BenchLM](https://benchlm.ai/newsletter/issues/2026-08-27)
- 날짜의 신뢰도가 업체별로 달라 확정·잠정 구분이 필요 — [Vorp Labs](https://vorplabs.com/models/deprecations)
- 같은 모델도 경로에 따라 은퇴일이 다를 수 있음(Bedrock·Azure) — [검색 요약, BenchLM 출처](https://benchlm.ai/newsletter/issues/2026-08-27)
- 공급사 페이지를 매일 읽고 git으로 가격 이력을 남기는 무료 JSON API가 있음 — [modelfax](https://github.com/bytebrujo/modelfax)
- 은퇴 날짜에 대체 모델 제안을 붙인 무료 추적기가 있음(호응 수치는 미확인) — [Model Graveyard](https://www.producthunt.com/posts/1192198)

### Inferences
- 달력: API 지원 종료, 모델 은퇴, 요금 변경 시행일을 기한으로 올린다. 확정·잠정을 구분한다.
- 지표: AI API 가격(입력·출력 100만 토큰 단가)과 구독 요금 변화를 지표로 둔다. 원화 환산은 사이트 고유 가치가 될 수 있다.
- 엔티티 페이지: 도구별 변경 이력을 쌓아 "Claude Code의 지난 석 달" 같은 시간순 보기를 만든다. 깃밥(레포 스냅숏)이나 비교 글(정적)과 가장 크게 갈리는 지점이다.
- 이슈 스레드: 제품 소식을 업계 사건에 묶는다. 예: 모델 가격 인하 소식을 경쟁 흐름 이슈에 연결.
- 용어집: 새 개념(예: MCP, 하네스) 첫 등장 때 링크해 소식 본문을 짧게 유지한다.
- 항목 틀: "무엇이 바뀌었나 / 누가 영향받나 / 지금 할 일(없음 포함) / 기존 대안 / 기한"의 고정 형식. "할 일 없음"을 허용한다.
- 신뢰 장치: AI 생성 표시, 공식 출처 링크, 기존 정정 기능을 유지한다.
- 하지 말 것: 레포 점수 경쟁, 도구 디렉터리 덮어쓰기, 스타 수 순위 재탕, GN⁺식 해외 글 번역 요약.

### Gaps
- 한국 웹 개발자가 실제로 이런 판단형 항목을 원하는지 보여 주는 수요 자료는 이번 범위에서 얻지 못했다.
- 도구 변경 이력의 수집 부담(공식 변경 내역을 믿을 만하게 얻을 수 있는지)은 이 조사에서 검증하지 않았다.
