## 보류된 이슈

- 2026-10-28: Claude Code의 웹 페이지 읽기 도구(WebFetch)가 Reuters, AP, 연합뉴스, BBC 페이지를 읽지 못한다("unable to fetch"). 한국일보 등 다른 매체는 읽힌다. 웹 검색 결과에는 이 매체들의 제목·요약·주소가 나올 수 있다. 그래서 `/brief`의 출처가 통신사보다 Euronews 같은 매체에 몰리고 "보도에 따르면"이 늘어난다. 이미 수집한 날짜는 다시 수집할 수 없으므로, 통신사 RSS 같은 확인 수단은 plan의 1.5단계(출처 개선)에서 정한다.

## 결정

- 2026-10-28: 실제 `/brief`(main, 실제 `data/`)는 1.5단계(출처 개선)가 끝날 때까지 실행하지 않는다. 출처가 약한 데이터가 쌓이지 않게 하기 위해서다. 첫 실제 실행이 KST 어제 하루부터 시작하므로 미뤄도 잃는 데이터는 없다(사용자 결정).
