## 만든 것

브리프에 **빌더 탭**이 생겼다. 코딩 도구, 모델, 보안, 프레임워크, 플랫폼의 변화를 공식 소스 26개에서 받아 기계로 거르고, Claude가 하루 0~4건을 쓴다.

- **받기:** `node src/cli.ts builder-fetch --run <파일>`이 소스를 받아 후보 목록(`work/builder.candidates.md`)을 만든다. 소스별 받은 시각을 따로 두어 실패한 소스의 기간을 잃지 않는다.
- **숫자 행:** 가격·한도·지원 종료 문서의 표 행을 바뀐 날에만 저장해 비교한다. 원문은 `<데이터>/builder-raw/`에 로컬로만 둔다.
- **쓰기:** `builder-check`로 검사하고 `builder-apply`로 한 트랜잭션에 저장한다. 실패하면 `builder-fail`로 받지 못함을 남긴다.
- **달력:** 확정 기한은 일정이 되고 D-7에 한 번 다시 알린다. 종료일이 늦어지면 연기로, 앞당겨지면 예정일을 고친다.
- **사이트:** 빌더 탭, 정적 HTML, 검색, RSS, 소개 절, 정정 표시. 파일은 달별 `builder-items-YYYY-MM.json`이다.
- **백업:** 형식 7, `builder.json`. 후보 글과 원문은 들어가지 않는다. 스키마는 11이다.
- **문서:** `.claude/skills/brief/SKILL.md`, `docs/operations.md`, README 두 파일, `LICENSE`, `docs/design.md`.

소스를 끄려면 `src/builderSources.ts`의 두 목록에 이름을 넣는다. 항목 정정은 뉴스와 같은 `correct` 명령이다.
