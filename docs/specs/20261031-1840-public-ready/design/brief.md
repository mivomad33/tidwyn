# 디자인 요청서: Tidwyn 브랜드 표시와 공개 준비 화면

## 제품

- Tidwyn은 AI가 매일 한국·세계·IT·AI 뉴스를 모아 쉬운 말로 바꿔 쓰고, 뉴스를 이어지는 이슈로 묶어 흐름을 보여 주는 개인 뉴스 아카이브다. 주소는 `tidwyn.vercel.app`이다.
- 만든 사람이 매일 폰으로 보고, 공개 사이트라 누구나 볼 수 있다. 곧 검색엔진 등록과 GeekNews·Threads 공유로 처음 오는 사람이 생긴다.
- 첫인상에서 줘야 할 것: 차분하고 믿을 만한 읽을거리. 자극적인 뉴스 매체나 AI 제품의 화려함이 아니다. 작은 크기에서도 Tidwyn임을 알아볼 수 있어야 한다.

## 이번에 정하는 것

화면 3·4·5는 지금 사이트의 글자, 색, 간격, 카드 모양 안에서 만든다. 탐색하는 것은 주로 1·2의 표시(마크, 글자 처리, 구성)다.

## 실제 데이터

지어낸 예시를 쓴다. 실제 뉴스, 실제 인물 이름은 쓰지 않는다.

- 이름: `Tidwyn`. 설명: `AI가 매일 모아 쉬운 말로 바꿔 쓴 한국·세계·IT·AI 뉴스 요약과 이슈 흐름`
- 뉴스 줄 예시: 제목 20~40자, 대분류(정치, 경제, 사회, 국제, IT·AI, 과학·건강, 문화·스포츠), 날짜 `10월 30일`
- 정정 사유 예시: `금리 인상 폭을 0.5%포인트에서 0.25%포인트로 바로잡았다.` 긴 경우 80자
- 메일 주소: `mivomad33@gmail.com`

## 과제

1. 메신저에 붙은 링크 미리보기를 보고 무슨 사이트인지 말한다.
2. 탭이 여러 개 열린 브라우저에서 Tidwyn 탭을 찾는다.
3. 잘못된 주소로 왔을 때 오늘 브리프로 돌아간다.
4. 뉴스의 틀린 내용을 어디로 알릴지 찾는다.
5. 목록에서 고친 뉴스를 알아보고 무엇이 바뀌었는지 안다.

## 제약

- 지원 폭: 모바일 우선(375px)과 1440px. 라이트·다크는 기기 설정을 따른다. 언어는 한국어다.
- 기술: Vite + React 정적 사이트, 외부 글꼴을 받지 않는다(Pretendard가 있으면 쓰고 없으면 시스템 글꼴). 공유 이미지와 아이콘은 정적 파일로, 외부 이미지와 글꼴 파일에 기대지 않는다. 글자를 쓰면 윤곽선으로 바꾸거나 저작권 문제가 없는 글꼴만 쓴다.
- 브랜드 자산: 로고와 정해진 브랜드 색은 없다. 사이트 토큰은 다음과 같다(바꾸지 않는다). 라이트: 바탕 `#ffffff`, 글자 `#1d1d1f`, 흐린 글자 `#6b6b70`, 선 `#ececee`, 상자 `#f5f5f7`, 강조 `#c2410c`, 강조 바탕 `#fff1e8`. 다크: 바탕 `#161618`, 글자 `#ececee`, 강조 `#fb923c`, 강조 바탕 `#3a2414`.
- 바꾸지 않을 것: 기존 화면의 레이아웃, 색 토큰, 글꼴, 머리글의 글자 이름 표시.
- 자주 보이는 유행(보라색 그라데이션, 반짝이 아이콘, AI 상징, 신문·지구본 아이콘 그대로 쓰기)을 피한다.
- 일정을 알리는 시계·달력, 번개, 로봇 같은 뜻을 잘못 전하는 상징을 쓰지 않는다.
