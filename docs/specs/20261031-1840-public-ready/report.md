## 만든 것과 사용법

- 브리프·이슈·인물·기관·국가·지표·소개 페이지마다 제목, 설명, 본문이 든 HTML을 빌드합니다. 자바스크립트를 켠 방문자는 지금과 같은 앱 화면을 봅니다. 앱을 받지 못하거나 앱 코드를 처음 실행하다 오류가 나면 정적 본문이 보입니다.
- 메타, OG, canonical, 구조화 데이터, `robots.txt`, `sitemap.xml`, `rss.xml`, 진짜 404, 파비콘, 공유 이미지를 더했습니다.

- 결과물 검사와 배포 뒤 점검이 공개 페이지와 수집기용 파일까지 봅니다.

새 명령은 사용자가 직접 실행합니다.

```bash
node src/cli.ts correct --file <JSON>
```

JSON에는 `date`, `key`, `reason`, `fields`를 씁니다. 사유는 공개되고 지울 수 없으니 무엇을 어떻게 고쳤는지만 씁니다. 메일, 주소, 전화번호 모양은 거부됩니다. 고치기 전 DB 사본이 `snapshots/`에 남고 마크다운을 다시 만듭니다. 백업과 배포는 다음 `/brief`가 합니다. 자세한 내용은 `docs/operations.md`에 있습니다.
