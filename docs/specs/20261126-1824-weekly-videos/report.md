- [프로세스] Python의 텍스트 모드 쓰기(`open(p,'w')`)가 Windows에서 줄바꿈을 CRLF로 바꿔 여러 파일이 통째로 바뀐 diff가 될 뻔했다(result-auditor가 잡음). `newline=''`로 쓰거나 Edit 도구를 쓴다.
- [명세서] 구현 중(2026-11-26 밤) youtube-insight가 스키마 v5로 바뀌었다. 명세서는 v4 모양과 사본 한 번만 정했기에, 분야를 읽는 곳과 사본 다시 뜨기를 사용자에게 물어 정했다.
- [프로세스] 사용자가 화면을 보며 고칠 것을 주는 중에 E2E를 돌려 지적받았다(고치기만 하고 테스트는 정해진 뒤 한 번에).
- [프로세스] 맥락 요약 뒤 영어로 답해 사용자가 여러 번 바로잡았다(전역 규칙: 늘 한국어).
- [프로세스] 칩 모서리를 8px로 줄일 때 폰 누를 곳의 투명 테두리(8px)를 빼먹어 보이는 모서리가 0이 되어 직사각형이 됐다. 바꾼 뒤 화면으로 보지 않고 알렸다.
