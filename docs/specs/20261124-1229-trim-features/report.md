## 만든 것

- 영상(7·8·9.6·9.7), 빌더 탭(9.8·9.9), 수요(9.95~9.98) 기능을 코드·명령·사이트 화면·데이터 파일·테스트·문서에서 지웠다. 남은 기능은 뉴스 브리프, 이슈, 인물·용어, 일정, 지표, 읽은 표시, 정정, 방문 통계다.
- DB 업그레이드 15: 지운 기능의 표를 지우고, 빌더 항목만 근거였던 일정(뉴스 연결이 없는 일정)을 지운다. 백업 형식 11: `builder.json`·`demand.json`을 쓰지 않고, 옛 형식(1~10) 백업도 복원한다.
- `start --deploy-only`(배포만 실행): 수집 없이 백업·사이트 빌드·배포·push·요약만 한다. 요약은 대상 날짜를 "이번 실행에서 수집하지 않음"으로 보인다. 사용법은 `docs/operations.md`의 "배포만 실행".
- 사이트: 옛 탭 저장값·옛 주소 해시는 뉴스 기본 탭으로, `/videos/...`는 404로 간다. 브라우저에 남은 옛 빌더·수요 읽음 기록은 세지 않는다.
