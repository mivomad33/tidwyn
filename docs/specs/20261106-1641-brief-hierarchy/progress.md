## 재량 결정

- 기준선: 2026-11-06(같은 날) write-spec 때 1cc2a3c를 측정 데이터로 빌드해 잰 값(`.test-data/u2base`, 명세서 1장)을 전 값으로 쓴다. 후 값도 오늘 잰다.
- 상자 펼침: `BriefMark.weekOpen`(history.state). 새 기록은 날짜 화살표가 `state`로 넘긴 펼침만 잇고, 기록 되돌리기(pop·back_forward)만 남긴 값을 되살린다. 이를 위해 `Link`에 `state`를 더했다. 브리프 기록 표시 효과에 entryId를 더해 같은 날짜의 새 기록에도 표시를 남긴다.
- 일정 출처 링크: `nameLink`를 `sourceLink`(글·주소)로 바꿔 앱·정적 HTML이 같이 쓴다. 일정 이름 `a.t` 밑줄 규칙과 정적 `.ev .t` 넓힘 규칙은 쓰이지 않아 지웠다.
- 섹션 탭 고정(S14): DOM을 TopBar 다음으로 옮기고 `.tabs { order: 1 }`로 `#root`(flex 세로) 맨 끝에 놓아 `sticky; bottom: 0`을 그대로 쓴다. 모양·안전 영역·좁은 폭 규칙이 그대로다.
- 누를 곳: 배경·테두리가 있는 부품은 투명 테두리 + `background-clip: padding-box` + 안쪽 그림자 테두리로, 글 링크는 아래 여백만, 줄 링크는 여백 + 음수 여백으로 넓혀 보이는 크기를 지켰다.
- 빌더 항목 제목: 뉴스 줄처럼 줄 전체가 버튼이라(4.2-1) 제목을 `h3`에서 버튼 안의 글로 바꿨다. 뉴스 줄도 제목 요소가 없고, 묶음 소제목('도구 변화' 등)은 그대로 제목이다. `h3 > button`은 접힌 칸까지 제목 글이 돼 고르지 않았다.
- 펼침 표시: 접힌 줄 아래 따로 한 줄이던 ▾를 줄 끝(읽음 버튼 아래 빈 칸)에 두어 줄을 늘리지 않는다.
