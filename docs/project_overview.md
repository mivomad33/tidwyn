# 프로젝트 개요

Tidwyn(타이드윈)은 매일 받는 뉴스 브리프를, 뉴스를 쌓고 서로 연결해 흐름까지 보여 주는 개인 뉴스 아카이브로 키우는 프로젝트다.
목표, 범위, 원칙, 세부 설계는 [시드 문서](project_seed.md)를 원본으로 본다. 이 문서에는 시드에 없는 현재 상태, 결정, 미정, 다음 할 일만 둔다.

## 결정

- 지난 브리프(기존 클라우드 예약 작업이 만든 것)는 가져오지 않는다. Tidwyn 첫 수집일부터 새로 쌓는다.
- 기존 클라우드 예약 브리프(매일 03:45 KST, 푸시 메시지)는 Tidwyn이 매일 안정적으로 돌기 시작할 때까지 병행하고, 그 뒤 끈다.

## 현재 상태

- 저장소에는 시드 문서, 작업 규칙(`CLAUDE.md`), Serena 설정만 있다. 코드는 아직 없다.
- GitHub 원격 저장소는 아직 연결되지 않았다.

## 정해지지 않은 것

- 기술 스택(언어, 로컬 DB, 사이트 빌드 도구): 계획 단계에서 Claude가 제안한다. Pagefind(검색)와 GitHub Pages(배포)만 시드에 정해져 있다.
- 단계 구성(무엇부터 만들지)
- 대분류 고정 목록과 소분류 목록(시드에는 대분류 예시만 있음)
- 유튜브 정보성 카테고리의 정확한 목록: 개발할 때 확인한다.
- 자막 수집이 막혔을 때 Gemini API의 비용과 조건: 확인 필요.
