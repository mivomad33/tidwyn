# 프로젝트 개요

Tidwyn(타이드윈)은 매일 받는 뉴스 브리프를, 뉴스를 쌓고 서로 연결해 흐름까지 보여 주는 개인 뉴스 아카이브로 키우는 프로젝트다.

- [시드 문서](project_seed.md): 받은 원본. 세부 설계(데이터 설계, 수집 단계, 화면 구성, 용량 계산 등)를 담는다.
- [진행 계획](plan.md): 이후 기준. 목표, 큰 방향의 결정, 단계와 상태, 다음 할 일을 담는다.

## 현재 상태

- 저장소에는 문서, 작업 규칙(`CLAUDE.md`), Serena 설정만 있다. 코드는 아직 없다.
- GitHub 원격 저장소는 아직 연결되지 않았다(3단계에서 만든다).
